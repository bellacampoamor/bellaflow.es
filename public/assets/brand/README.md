# Bella Flow: merkbestanden

Alle bestanden zijn PNG met transparante achtergrond. In de app bereikbaar via `/assets/brand/<bestand>`.

| Bestand | Formaat (px) | Gebruik |
|---|---|---|
| `bellaflow-logo-full-tagline.png` | 2400 × 502 | Volledig logo met tagline: loginscherm, documenten |
| `bellaflow-logo-large.png` | 1600 × 293 | Breed logo: kopteksten, facturen |
| `bellaflow-logo-medium.png` | 800 × 147 | Navigatiebalk |
| `bellaflow-logo-small.png` | 480 × 98 | Compacte balk, zonder "by Rick" |
| `bellaflow-logo-stacked.png` | 1200 × 863 | Alleen tekst, gestapeld |
| `bellaflow-beeldmerk-1.png` | 1024 × 1024 | Beeldmerk los |
| `bellaflow-beeldmerk-2.png` | 1024 × 1024 | Beeldmerk in cirkel: avatar |
| `bellaflow-favicon-{16,32,48,180,192,512}.png` | vierkant | Favicon, app-icoon (180 = Apple, 192/512 = PWA) |

De logo's zijn ontworpen voor een lichte achtergrond; de donkerblauwe tekst valt weg op donker.
