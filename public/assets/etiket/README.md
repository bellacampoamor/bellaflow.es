# Etiket: beeldmerk

`beeldmerk-bella.png` is het beeldmerk dat rechts op elk prijsetiket staat (DYMO 30321, 89 x 36 mm): het staande logo van Bella, BELLA FURNITURE & OUTDOOR, wit op een zwart vlak.

- De printer drukt alleen zwart; grijs wordt zwart of wit.
- Staand of liggend mag: een liggend beeld wordt een kwartslag gedraaid, zodat het verticaal op het etiket staat.
- Vlak op het etiket: 11 x 31 mm. Ontbreekt het bestand, dan staat er een zwart vlak met BELLA.
