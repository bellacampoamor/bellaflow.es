# Etiket: beeldmerk

Zet hier `beeldmerk-haco.png` neer: het beeldmerk van Ha-Co dat rechts op elk prijsetiket staat (DYMO 30321, 89 x 36 mm).

- Zwart op een witte of transparante achtergrond; de printer drukt alleen zwart.
- Staand of liggend mag: een liggend beeld wordt een kwartslag gedraaid, zodat het verticaal op het etiket staat.
- Vlak op het etiket: 11 x 31 mm. Ontbreekt het bestand, dan staat er een zwart vlak met HA-CO.
